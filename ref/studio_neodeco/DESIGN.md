## Brand & Style
The design system manifests a hyper-curated, tactile digital atelier tailored for Gen Z creators (teens and early twenties) producing Instagram-first content, scrapbooks, and photo collages. It bridges the precision of a high-end photo editing suite with the playful, dopamine-driven expression of sticker books and Y2K stationery.

The design movement combines **Minimalist High-Function Workspace** with **Frosted Glass Neomorphism (Soft Tactility)**:
- **Foundational Canvas:** Ultra-clean, neutral graphite surfaces keep the user's photography and creative assets front and center without competing color casts.
- **Expressive Micro-Interactions:** Electric pastel accents (neon peach-pink, creamy butter yellow, cyber mint) designate tactile action, playful tool shifts, active selections, and state transitions.
- **Emotional Target:** Effortless cool, empowering creator autonomy, swift tactile delight, and an intuitive "flow state" optimized for thumbs and micro-gestures.

## Colors
The palette is engineered around dark workspace fidelity with effortless light mode parity. In dark mode (default for creative studios), the deep graphite backgrounds yield maximum contrast for photo manipulation without eye fatigue.

### Color Roles & Ratios
- **Base Canvas & Layering (Graphite Matrix):**
  - Dark Surface 0 (Base Canvas Background): `#0A0A0B`
  - Dark Surface 1 (Toolbars & Floating Panels): `#121212`
  - Dark Surface 2 (Sheets, Cards, Modals): `#1E1E1E`
  - Dark Surface 3 (Active Item / Inactive Pill / Divider): `#2A2A2E`
  - Light Surface 0 (Light Mode Base): `#F7F7F8`
  - Light Surface 1 (Light Mode Elev 1): `#FFFFFF`
  - Light Surface 2 (Light Mode Modals/Sheets): `#EFEFEF`
- **Primary Electric Peach-Pink (`#FF5376`):** The primary energy signature. Used for key call-to-actions, active canvas bounding boxes, transform handles, primary tool triggers, and export badges.
- **Secondary Cyber Mint (`#4EEDB2`):** Communicates success, alignment guides, snapping indicators, smart magnetic guides, and affirmative micro-badges.
- **Tertiary Butter Yellow (`#FFE866`):** Reserved for playful stickers, quick-fave tags, tip bubbles, and layer order highlights.
- **Neutral Foreground & Text:**
  - Text Primary: `#FFFFFF` (Dark) / `#111112` (Light)
  - Text Muted / Subtitle: `#90909A` (Dark) / `#6B6B76` (Light)
  - Border Hairline: `rgba(255, 255, 255, 0.08)` (Dark) / `rgba(0, 0, 0, 0.06)` (Light)

## Typography
Typographic hierarchy emphasizes immediate legibility, high density of tools without visual clutter, and seamless Korean/Latin integration.

### Font Pairing Strategy & Pretendard Stack
- **Primary English & Display:** **Plus Jakarta Sans** delivers geometric precision with subtly rounded apertures, resonating directly with youthful, design-led editorial styling.
- **Korean Script Fallback Stack:** In implementation, declare `font-family: 'Plus Jakarta Sans', 'Pretendard Variable', Pretendard, -apple-system, BlinkMacSystemFont, system-ui, sans-serif;`. Pretendard matches Plus Jakarta Sans' optical balance, x-height, and neutral tracking for Korean glyphs.
- **Micro-Labels:** Use uppercase for functional status tags (`label-sm`), pairing tightened tracking with bold weights to maintain legibility at low point sizes on mobile viewports.

## Layout & Spacing
The layout model follows a **Viewport-Anchored Creative Workspace** philosophy tailored for Progressive Web Apps (PWA):

- **Safe-Area First:** Hard constraints anchored to `env(safe-area-inset-top)` and `env(safe-area-inset-bottom)` to accommodate mobile edge swipes and dynamic notches.
- **Vertical Hierarchy:**
  - **Top Navigation Bar (48px - 56px):** Project status, undo/redo icons, quick export button.
  - **Fluid Viewport Canvas Area:** Dynamically scaled pinch-to-zoom workspace maintaining Instagram story/post aspect ratios (9:16, 4:5, 1:1) centered via dynamic flex space.
  - **Floating Precision Controls:** Floating pill toolbars hovering 16px above bottom drawers.
  - **Bottom Action Dock / Modal Sheet (64px - 280px):** Fast finger-reach thumb zone for asset browsing, filters, sticker packs, and layer organization.
- **Responsive Adaptations:**
  - *Mobile (<640px):* Full-bleed canvas with drawer-based bottom-up overlays.
  - *Tablet & Foldables (640px - 1024px):* Split-view layout; bottom sheets convert into a fixed 320px right-hand floating panel, maximizing center artboard scale.

## Elevation & Depth
Depth separates the user's interactive artwork from the software chrome using **Aero-Dark Glassmorphism** layered with translucent, noise-free acrylic surfaces:

- **Level 0 (Stage/Canvas):** Matte base `#0A0A0B`. Zero shadow.
- **Level 1 (Dock & System Chrome):** Semi-opaque background (`rgba(18, 18, 18, 0.82)`) paired with `backdrop-filter: blur(20px) saturate(160%)` and a crisp `1px` inner highlight border (`rgba(255, 255, 255, 0.08)`).
- **Level 2 (Floating Action Pills & Context Menus):** `rgba(30, 30, 30, 0.90)` with `backdrop-filter: blur(24px)`, bounded by a soft atmospheric drop shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.55), 0 2px 6px rgba(0, 0, 0, 0.3)`.
- **Level 3 (Bounding Boxes & Active Layer Handles):** High-precision vector outlines (`1.5px solid #FF5376`) paired with glowing anchor dots that cast a soft 6px perimeter glow: `0 0 10px rgba(255, 83, 118, 0.4)`.

## Shapes
The design system adopts a **Pill-Centric (`roundedness: 3`)** shape grammar to project friendliness, organic playfulness, and high-velocity tactile navigation:

- **Full Radius (Pill / 9999px):** Standard interactive buttons, filter category tags, brush slider knobs, layer selection tags, and floating contextual toolcapsules.
- **Surface Panels (`rounded-xl` / 1.5rem to 2rem):** Bottom sheets, asset pickers, and sticker drawer containers feature rounded top edges (`border-top-left-radius: 24px; border-top-right-radius: 24px`).
- **Canvas Selection Anchors:** Circular nodes (`size-3` or `size-3.5` with `rounded-full`) positioned at rotation and scale bounds, facilitating smooth touch targets.

## Components

### 1. Buttons & Action Pills
- **Primary CTA ("Export / Save"):** Full-pill shape, solid `#FF5376`, dark text `#121212`, `title-md`, tactile squash micro-animation on active press (`transform: scale(0.96)`).
- **Secondary Workspace Buttons:** Translucent glass fill `rgba(255, 255, 255, 0.08)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#FFFFFF`.
- **Icon Quick-Buttons:** 44px x 44px round circles for undo, redo, zoom-to-fit, and layer inversion.

### 2. Category & Filter Chips
- **Inactive:** Pill shape, background `#1E1E1E`, text `#90909A`, border `1px solid transparent`.
- **Active:** Background `#FFE866`, text `#121212`, font weight `600`, with smooth horizontal swipe transitions.

### 3. Floating Context Menu (Layer Manipulation)
- Positioned floating directly adjacent to selected canvas elements.
- Ultra-compact horizontal pill dock containing: *Duplicate*, *Lock*, *Front/Back*, *Mask*, *Delete*.
- Icons paired with subtle vertical dividing lines (`1px solid rgba(255, 255, 255, 0.1)`).

### 4. Precision Bottom Sheets & Drawers
- Dismissible sheet with centered grab handle (`36px x 4px`, `rgba(255, 255, 255, 0.2)`).
- Two snap-points: 40% height for rapid sticker/filter dragging; 85% height for detailed asset library navigation.
- Built-in grid for photo cutouts, stickers, and deco overlays with lazy-loaded smooth previews.

### 5. Canvas Slider & Value Adjusters (Opacity / Brush Size / Blur)
- Minimalist track (`4px` height, background `#2A2A2E`).
- Filled indicator utilizing vibrant gradient (`#FFE866` to `#FF5376`).
- Pill-shaped thumb (`20px x 20px`) with high contrast white center and dynamic numeric value bubble floating above during active scrub.

### 6. Layer Manager List Items
- Reorderable draggable rows with soft haptic feedback on touch-and-hold.
- Thumbnail preview with `rounded-md` (8px), layer name, visibility toggle eye-icon, and lock toggle.
- Selected state highlighted with a Cyber Mint (`#4EEDB2`) left indicator bar.
