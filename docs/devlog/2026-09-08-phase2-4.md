## 만든 것

### Phase 2 - 스티커, 글자, 히스토리

- **히스토리 30단계** (`store/historyStore.ts`)
  스냅샷에는 레이어 구조만 담고 사진은 `imageId`로만 참조한다.
  모든 레이어 변경이 `projectStore`의 `applyLayers` 한 경로를 지나게 만들어, 액션이 늘어도 기록을 빼먹지 않는다.
  결과가 이전과 같으면(맨 위 레이어를 또 맨 위로 보내는 등) 기록도 갱신도 하지 않는다.
- **스티커** (`assets/stickerCatalog.ts`, `canvas/AssetContent.tsx`)
  카테고리 탭 + 그리드. 연달아 탭하면 겹치지 않게 어긋나 놓인다.
  URL 에셋 이미지 캐시를 사진 캐시(IndexedDB)와 같은 구현(`utils/imageLoader.ts`)으로 통일했다.
- **글자** (`fonts/`, `canvas/TextContent.tsx`, `components/TextEditorModal.tsx`)
  웹폰트 4종을 고른 시점에 동적 로드한다. 스타일시트가 붙기를 기다린 뒤 `document.fonts.load`를 부르고,
  도착하면 캔버스를 다시 재고 다시 그린다. 더블탭으로 재편집, 내용을 비우고 완료하면 삭제된다.
- **컨텍스트 바** (`components/LayerContextBar.tsx`)
  순서 4종, 복제, 좌우반전, 삭제, 투명도. 투명도는 드래그당 한 번만 히스토리에 남는다.

### Phase 3 - 배경, 도형, 자유 그리기

- **배경 4종** (`canvas/BackgroundContent.tsx`)
  단색 / 그라데이션 / 무늬 / 사진 흐리게. 그라데이션은 각도를 두 점으로 바꿔 세로로 긴 캔버스에서도 색이 끝까지 나오고,
  무늬는 늘리지 않고 타일로 반복해 비율마다 찌그러지지 않는다.
- **도형 6종** (`canvas/ShapeContent.tsx`)
  전부 원점 중심으로 그려 회전축을 사진/스티커/글자와 통일했다.
  패널에서 색을 고르면 선택된 도형은 즉시 바뀌고, 선택이 없으면 다음에 넣을 도형의 색이 된다.
- **자유 그리기** (`canvas/useBrushDrawing.ts`, `utils/strokeRaster.ts`, `layers/importDrawing.ts`)
  점은 ref에 쌓고 Konva 노드만 직접 갱신한다. 미리보기 획은 별도 레이어에 둬서 사진과 스티커를 다시 그리지 않는다.
  손을 떼면 획을 이미지로 굽고(내보내기 배율에 맞춰 2배 해상도) 일반 레이어로 바꾼다. 획 하나가 레이어 하나.

### Phase 4 - 내보내기, 공유, 자동 저장

- **내보내기** (`export/renderProject.ts`)
  편집 캔버스를 배율만 올려 다시 그린다. Konva가 스테이지 배율을 곱하므로 `pixelRatio = 목표배율 / 스테이지배율`.
  찍기 전에 선택을 풀고 한 프레임 기다린다(Transformer가 결과물에 찍히는 것 방지).
- **공유** (`export/share.ts`)
  `navigator.share({ files })`가 주 경로, 다운로드 링크는 폴백. 공유 시트를 닫은 것(AbortError)은 실패로 보지 않는다.
- **자동 저장** (`store/autoSave.ts`, `storage/projectRepo.ts`)
  프로젝트 스토어를 구독해 800ms 모아서 IndexedDB에 쓴다. 홈의 "이어서 편집"에 레이어 수를 표시한다.

### 계획 외 추가

| 결정 | 대안 | 이 쪽을 고른 이유 |
|---|---|---|

| 획을 손 떼는 순간 이미지로 굳힘 | 점 배열을 레이어에 보관 | 점이 쌓이면 렌더가 무거워지고 실행취소 스냅샷도 커진다 |

| 컨텍스트 바를 흐름 밖(absolute)으로 | 흐름에 배치 | 선택할 때마다 캔버스 높이가 바뀌어 그림이 위아래로 튄다 |
| 이미지 정리는 편집 종료 시점에만 | 저장할 때마다 정리 | 편집 중에 지우면 실행취소가 가리키는 이미지가 사라진다 |
| 폰트 로딩에 6초 타임아웃 + 캐시 삭제 | 실패까지 대기 | 네트워크가 끊기면 요청이 실패하지 않고 매달려 재시도 기회조차 없다 |

## 겪은 문제

### 1. "이어서 편집"이 흰 화면으로 죽음

- **증상**: 저장된 작업물을 열면 캔버스가 통째로 사라지고 아무 반응이 없음
- **원인**: 파괴된 Transformer에 `forceUpdate()`를 호출. StrictMode가 마운트를 되감을 때 앞선 마운트의 스테이지가 파괴되는데, 그 노드를 가리키던 상태가 새 ref가 들어오기 전까지 잠깐 남는다. 그 틈에 IndexedDB에서 비동기로 도착한 이미지가 콜백을 부르면서 이미 없어진 앵커를 건드렸다
- **조치**: `node.getStage()`로 살아 있는지 확인하는 `isLive` 가드를 명령 거는 지점 전부에 추가
- **재발 방지**: CLAUDE.md 알려진 함정에 기록

### 2. 스티커 패널의 왼쪽 아래 스티커가 안 눌림

- **증상**: 특정 위치의 스티커만 탭이 먹지 않음
- **원인**: 개발용 debug 버튼(`fixed bottom-20 z-50`)이 패널 위에 떠서 탭을 가로챔
- **조치**: 디버그 오버레이를 패널보다 낮은 z로 내리고, 패널/컨텍스트 바/툴바에 z를 명시
- **여담**: 같은 문제가 뒤에 한 번 더 났다. 컨텍스트 바를 툴바 위로 띄우면서 이번엔 debug 버튼이 가려져 누를 수 없게 됐고, 버튼을 더 위로 올려 해결했다

### 3. 레이어를 고를 때마다 캔버스가 튐

- **증상**: 자동 테스트에서 좌표가 계속 어긋남. 확인해 보니 선택할 때마다 캔버스 위치가 이동
- **원인**: 컨텍스트 바가 흐름에 있어서 나타났다 사라질 때마다 캔버스 영역 높이가 바뀜
- **조치**: 컨텍스트 바를 툴바 위에 띄우는 방식으로 변경
- **메모**: 테스트가 아니었으면 "손으로 맞춰 둔 위치가 왜 자꾸 움직이지" 하고 한참 헤맸을 문제

### 4. 같은 화면에 "뒤로" 버튼 두 개

- **원인**: 상단 바의 뒤로(편집 나가기)와 순서 바꾸기의 뒤로가 겹침
- **조치**: 순서 라벨을 위/아래 표현으로 바꿈 (맨아래 / 아래 / 위 / 맨위)

## 열어 둔 것

**결정이 필요한 것**

- 테스트 러너(vitest): CLAUDE.md 방침대로 순수 함수 테스트를 쓰려면 필요한데 의존성 추가라 넣지 않음
- vite-plugin-pwa: 매니페스트와 아이콘만 넣어 설치는 되지만 오프라인 캐시는 없음

**알려진 한계**

- 스티커와 낙서의 히트 영역이 사각형이라 투명한 부분도 눌린다. 겹쳤을 때 밑을 고르기 어려워 레이어 목록으로 우회했다.
  알파 기준 히트로 바꾸려면 `cache()`가 필요한데 캐시 해상도에 화질이 묶여 내보내기가 흐려진다
- 사진 흐리게 배경은 맨 아래 사진만 쓴다
- 사진 자르기, 텍스트 자간과 배경 박스는 없음
- `public/mock-assets`는 전부 개발용 더미다. 실제 에셋이 나오면 `assets/stickerCatalog.ts`만 교체하면 된다

**실기기에서 볼 것 (Galaxy S25+)**

1. 실제 네트워크에서 웹폰트가 도착한 뒤 캔버스 글자가 다시 그려지는지
2. 그리기 손맛 - 손가락 굵기와 점 최소 간격(논리 좌표 2)이 맞는지, 빠르게 그을 때 각지지 않는지
3. 내보내기 - Brave Shields를 내리고 확인, 안드로이드에서 공유 시트가 뜨는지
4. 컨텍스트 바 여덟 칸이 한 줄에 들어가는지 (412px 기준 오른쪽 끝 376px)
